# Агрессивные крестики-нолики

Консольная игра в крестики-нолики против компьютера на Python. Размер поля от 3*3 до 9*9, ходы вводятся двумя цифрами, а текст игры печатается с эффектом печатной машинки.

## Требования

- Python 3 (проверялось на версии 3.13)
- Сторонние библиотеки не нужны: используются только `time`, `sys` и `random` из стандартной библиотеки

## Запуск

```bash
python3 tic_tac_toe.py
```

## Как играть

1. Введи размер поля числом от 3 до 9.
2. Выбери символ: `x` или `o` (латиницей).
3. Кто ходит первым, решается случайно.
4. Ход вводится двумя цифрами без пробела: номер строки и номер столбца. Например, `12` означает строку 1, столбец 2.
5. Побеждает тот, кто первым заполнит своим символом целую строку, целый столбец или одну из двух диагоналей. Если поле заполнено, а победителя нет, объявляется ничья.
6. Игру можно прервать в любой момент сочетанием `Ctrl+C`.

## Тесты

```bash
pip install pytest
python3 -m pytest -q test_tic_tac_toe.py
```

Тесты загружают код игры из `tic_tac_toe.py` в той же папке. Другой путь можно передать через переменную окружения `TTT_PATH`. Один из тестов использует `signal.SIGALRM`, которого нет в Windows, поэтому там он работать не будет.

## Особенности и ограничения

- Компьютер ходит случайно, никакой стратегии у него нет.
- В игровых сообщениях есть ненормативная лексика.
- Состояние игры хранится в глобальных переменных.
